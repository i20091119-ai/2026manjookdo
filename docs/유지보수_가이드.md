## 1. 전체 구조 이해하기

### 파일 구성

Apps Script 프로젝트에는 **2개 파일**이 있습니다.

| 파일명 | 종류 | 역할 |
|---|---|---|
| `Code.gs` | 스크립트 | 스프레드시트에서 데이터를 읽어옴 (서버) |
| `index.html` | HTML | 화면 표시, 통계 계산 (클라이언트) |

> 예전에는 `logo.html` / `scene.html`에 이미지 base64를 넣었지만, 지금은
> **구글 드라이브 파일에서 직접 읽어옵니다.** 두 파일은 더 이상 쓰지 않습니다.

### 동작 흐름

```
사용자가 웹앱 URL 접속
   ↓
비밀번호 입력 (3141)
   ↓
Code.gs의 checkPassword()가 서버에서 대조 → 맞으면 '토큰'을 발급
   ↓
index.html이 그 토큰을 들고 getAllData(토큰)을 한 번 호출
   ↓
getAllData()가 토큰을 확인한 뒤 4개 시트 + 로고/전경 이미지를 읽어서 반환
   ├── 자유관람
   ├── 교구대여
   ├── 학교·가족
   └── 캠프
   ↓
받아온 데이터를 index.html이 계산해서 표로 표시
```

**핵심 원칙 1**: `Code.gs`는 **데이터를 가져오기만** 하고,
통계 계산과 화면 표시는 전부 `index.html`이 합니다.

**핵심 원칙 2**: **비밀번호는 서버에만 있습니다.**
화면 소스를 아무리 뒤져도 비밀번호가 나오지 않습니다.
토큰은 6시간 뒤 만료되며, 만료되면 자동으로 잠금 화면으로 돌아갑니다.

## 2. 배포 방법 (가장 중요)

### 🚀 이번 개편판을 처음 올릴 때 (한 번만)

평소 배포와 달리 **파일 3개**를 갈아 끼우고 **권한을 다시 승인**해야 합니다.
순서대로 하세요.

#### ① 매니페스트를 편집기에 보이게 하기

1. 편집기 왼쪽 **⚙ 프로젝트 설정**
2. **"appsscript.json' 매니페스트 파일을 편집기에 표시"** 체크

체크하면 파일 목록에 `appsscript.json`이 나타납니다.

#### ② 파일 3개 교체

| 저장소 파일 | Apps Script 파일 |
|---|---|
| `src/Code.js` | `Code.gs` |
| `src/index.html` | `index.html` |
| `src/appsscript.json` | `appsscript.json` |

각각 **내용을 전부 지우고**(`Ctrl+A` → 붙여넣기) 갈아 끼웁니다.

> `logo.html` / `scene.html`이 남아 있다면 지워도 됩니다. 이제 안 씁니다.
> (지우지 않아도 동작에는 지장 없습니다)

#### ③ 저장 후 권한 다시 승인

`appsscript.json`에 이메일 확인 권한이 하나 늘었습니다.
**저장(`Ctrl+S`) → 함수 드롭다운에서 `diagnose` 선택 → 실행**

권한 승인 팝업이 뜨면 승인합니다.
("이 앱은 확인되지 않았습니다"가 나오면 **고급 → 프로젝트로 이동**)

실행 로그에 시트별 행 수가 찍히면 정상입니다.

#### ④ 재배포

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**

#### ⑤ 확인

시크릿 창에서 웹앱 URL을 엽니다.

- [ ] 잠금 화면이 뜨고 `3141`로 들어가진다
- [ ] **월말 집계** 탭에 `1-(03) 학생체험수학캠프` / `1-(04) 학생SW체험캠프` 숫자가 찬다
- [ ] 캠프 탭 4개가 보인다
- [ ] 표의 **📋 복사** 버튼이 "✅ 복사됨"으로 바뀐다
- [ ] `F12` → Console에서 `google.script.run.getFreeData()` 를 쳤을 때
      **함수를 찾을 수 없다는 오류**가 난다 (이게 정상입니다 — 막혔다는 뜻)

> 기존에 열어 둔 탭은 자동으로 잠금 화면으로 돌아갑니다. 정상입니다.

## 3. 월말 집계 탭

### 무엇을 하는 탭인가

선택한 연도·월의 보고서용 표 4개를 자동으로 만들어 줍니다.
각 표 우측의 **📋 복사** 버튼을 누르면 데이터가 클립보드에 복사되고,
한컴/엑셀 양식의 **첫 번째 데이터 셀**에 `Ctrl+V` 하면 그대로 들어갑니다.

> 복사되는 것은 **머리글과 합계 줄을 뺀 데이터 행만**입니다.
> 양식에 이미 머리글과 합계 수식이 있는 것을 전제로 합니다.

| 표 | 내용 | 사람 분류 |
|---|---|---|
| 1. 운영 현황 | 총괄 집계 양식 | 7분류: 유 / 초 / 중 / 고 / 교원 / 보호자 / 일반 |
| 2. 참여자 현황 | 거제 양식 | 6분류: 유아·일반을 '그 외'로 통합 |
| 3. 만족도 통계 | 문항1~5 × 5단계 | — |
| 4. 만족도 결과 | 만족도(%) | — |

**만족도(%) 계산식**

```
만족도(%) = [ '만족' 이상 답변 수의 합 / (설문 응답자 수 × 설문 문항 수) ] × 100
```

- 프로그램 운영 만족도 = 문항1~4 (문항 수 4)
- 강사 만족도 = 문항5 (문항 수 1)

### 프로그램 행을 고치려면

`index.html`의 **`REPORT_PROGRAMS`** 배열 하나만 고치면 4개 표에 모두 반영됩니다.
(904번째 줄 근처)

```javascript
{ grp:0, no:'1-(08)', name:'가족과 함께하는 수학체험교실',
  src:'prog',           // 어느 시트: 'free' | 'educ' | 'prog' | 'camp' | null
  field:'programType',  // 무엇으로 거를지
  filter:'가족수학체험프로그램',   // 시트 B열 값과 정확히 일치해야 함
  hasInstructor:true }, // 문항5(강사 만족도)가 있는 설문인지
```

- **`src:null`** 로 두면 데이터 원천이 없는 행이 되어 **회색 양식으로만** 표시됩니다.
  (경남학생수학탐구페스티벌, 기타, 직무연수가 여기에 해당)
- **`filter`에 배열**을 주면 여러 설문 종류를 한 행으로 합산합니다.

### 캠프가 어떻게 집계되는가

캠프 설문에는 응답자 구분 컬럼이 없습니다.
그래서 **캠프 종류명에 들어 있는 학교급**으로 분류합니다.

| 캠프 종류 | 분류 | 들어가는 행 |
|---|---|---|
| 초등학생 체험수학캠프 | 초 | 1-(03) 학생체험수학캠프 |
| 중학생 체험수학캠프 | 중 | 1-(03) 학생체험수학캠프 |
| 고등학생 인공지능수학캠프 | 고 | 1-(03) 학생체험수학캠프 |
| 초등학생 SW캠프 | 초 | 1-(04) 학생SW체험캠프 |

캠프 종류가 새로 생기면 두 곳을 함께 고칩니다.

1. `TABS` 배열 — 상세 탭을 추가하려면
2. `REPORT_PROGRAMS`의 `1-(03)` 또는 `1-(04)` 행 `filter` 배열 — 월말 집계에 넣으려면

> 종류명에 '초등/중학/고등'이 없으면 '일반'으로 분류됩니다.
> 종류명 규칙이 바뀌면 `schoolLevelOfCamp()` 함수를 고쳐야 합니다.

### 사람 분류 규칙

`classifyPerson()` 함수가 응답자 텍스트를 7분류로 바꿉니다.
**위에서부터 순서대로 검사**하므로 순서가 중요합니다.

```javascript
'학부모' 또는 '보호자' 포함  → 보호자     ← 반드시 맨 위
'교원'/'교사'/'교직원' 포함  → 교원
'유아' 포함                  → 유
'초등' 포함                  → 초
'중학' 포함                  → 중
'고등' 포함                  → 고
'학생' 포함 (구버전 단독 표기) → 초
그 외                        → 일반
```

`'초등학생 학부모'`가 `'보호자'`로 가는 이유가 이 순서 때문입니다.
학부모 검사를 아래로 내리면 학부모가 학생으로 집계되는 버그가 생깁니다.

## 4. 상황별 수정 방법

### 4-1. 비밀번호를 바꾸고 싶을 때

비밀번호는 **`Code.gs`(서버)에 있습니다.** `index.html`에는 없습니다.

바꾸는 방법이 두 가지입니다.

#### 방법 ① 스크립트 속성 (권장 — 코드에 안 남음)

1. Apps Script 편집기 왼쪽 **⚙ 프로젝트 설정** 클릭
2. 아래로 내려 **스크립트 속성** → **스크립트 속성 추가**
3. 속성 이름 `DASHBOARD_PW`, 값에 원하는 4자리 입력
4. **스크립트 속성 저장**

여기에 값이 있으면 코드의 기본값보다 **이 값이 우선**합니다.
재배포하지 않아도 바로 적용됩니다.

#### 방법 ② 코드 수정

**파일**: `Code.gs` · **위치**: 25번째 줄 근처

```javascript
const DEFAULT_PW    = '3141';
```

`'3141'` 부분을 원하는 4자리 숫자로 바꾸고 **재배포**합니다.

> 4자리가 아닌 비밀번호를 쓰려면 `index.html`의 `maxlength="4"`(입력칸)와
> 점 4개 표시 부분도 함께 수정해야 하므로, **4자리 유지를 권장**합니다.

> 비밀번호를 바꾸면 이미 로그인해 둔 사람은 **기존 토큰이 만료될 때까지(최대 6시간)**
> 계속 볼 수 있습니다. 즉시 끊으려면 배포 버전을 새로 올리세요.

### 4-2. 설문 문항 내용이 바뀌었을 때

**파일**: `index.html` · **위치**: 229~274번째 줄

| 상수명 | 줄 번호 | 해당 설문 |
|---|---|---|
| `FREE_ITEMS` | 229 | 자유관람 (8문항) |
| `EDUC_ITEMS_STUDENT` | 240 | 교구대여 학생용 (4문항) |
| `EDUC_ITEMS_TEACHER` | 246 | 교구대여 교원용 (4문항) |
| `PROG_ITEMS` | 256 | 학교·가족 (9문항) |
| `CAMP_ITEMS` | 268 | 캠프 (5문항) |

**수정 예시** — 자유관람 프1 문항을 바꾸려면:

```javascript
const FREE_ITEMS = [
  {label:'프1. 여기를 원하는 문구로 수정', type:'prog'},   // ← 이 부분
  {label:'프2. 프로그램이 이해하기 쉽게 잘 구성되었나요?', type:'prog'},
  ...
];
```

> `type`은 색상 구분용입니다. `'prog'`는 파란색(프로그램 문항), `'fac'`는 초록색(시설 문항)입니다.

### 4-3. 문항 개수가 늘거나 줄었을 때

**두 파일을 모두 고쳐야 합니다.**

#### ① `Code.gs` — 읽어올 열 범위 수정

예를 들어 캠프 문항이 5개 → 6개로 늘었다면 (C~G에서 C~H로):

**위치**: `getCampData_()` 함수 내부 (254번째 줄 근처)

```javascript
// 변경 전 — C열(2번)부터 5개
scores: toScores(row, 2, 5),

// 변경 후 — C열(2번)부터 6개
scores: toScores(row, 2, 6),
```

> **컬럼 번호는 0부터 시작합니다.**
> A=0, B=1, C=2, D=3, E=4, F=5, G=6, H=7, I=8, J=9, K=10, L=11, M=12, N=13, O=14, P=15

주관식 열 번호도 한 칸씩 밀리므로 함께 수정:

```javascript
comment1: cell(row, 8),   // 기존 7 → 8
comment2: cell(row, 9),   // 기존 8 → 9
```

#### ② `index.html` — 문항 목록에 추가

```javascript
const CAMP_ITEMS = [
  {label:'1. 참여한 프로그램 내용이 흥미로웠나요?', type:'prog'},

function mapProgRespondent(v) {
  const s = (v||'').trim();
  if (s.includes('학부모') || s.includes('보호자')) return '학부모 등 보호자';
  if (s.includes('학생')) return '학생';
  if (s.includes('교원') || s.includes('교사') || s.includes('교직원')) return '교원';
  if (s === '') return null;
  return '그외';
}
```

### 4-7. 만족도 응답 표현이 바뀌었을 때

> `'불만족'`을 `'만족'`보다 먼저 검사해야 합니다. 순서를 바꾸면

### 가장 먼저 할 일 — `diagnose()` 실행

**수동 백업**
Apps Script 편집기에서 코드 전체 선택(`Ctrl+A`) → 복사 → 텍스트 파일로 저장
