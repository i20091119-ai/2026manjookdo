## 1. 전체 구조 이해하기

### 파일 구성

Apps Script 프로젝트에는 총 **4개 파일**이 있습니다.

| 파일명 | 종류 | 역할 |
|---|---|---|
| `Code.gs` | 스크립트 | 스프레드시트에서 데이터를 읽어옴 (서버) |
| `index.html` | HTML | 화면 표시, 통계 계산 (클라이언트) |
| `logo.html` | HTML | 로고 이미지 base64 데이터 |
| `scene.html` | HTML | 전경 이미지 base64 데이터 |

### 동작 흐름

```
사용자가 웹앱 URL 접속
   ↓
비밀번호 입력 (3141)
   ↓
index.html이 Code.gs의 함수 4개를 동시 호출
   ├── getFreeData()     → 자유관람 시트
   ├── getEducData()     → 교구대여 시트
   ├── getProgramData()  → 학교·가족 시트
   └── getCampData()     → 캠프 시트
   ↓
받아온 데이터를 index.html이 계산해서 표로 표시
```

**핵심 원칙**: `Code.gs`는 **데이터를 가져오기만** 하고, 통계 계산과 화면 표시는 전부 `index.html`이 합니다.

## 2. 배포 방법 (가장 중요)

### 코드를 수정한 뒤 반드시 해야 하는 일

수정만 하고 저장하면 **웹앱에 반영되지 않습니다.** 반드시 재배포해야 합니다.

**단계별 절차:**

1. Apps Script 편집기에서 코드 수정
2. 상단 **저장** 버튼 클릭 (또는 `Ctrl+S`)
3. 우측 상단 **배포** 버튼 클릭
4. **배포 관리** 선택
5. 기존 배포 항목 오른쪽의 **연필(수정)** 아이콘 클릭
6. **버전** 드롭다운에서 **새 버전** 선택
7. **배포** 버튼 클릭

> ⚠️ **주의**: "새 배포"를 하면 URL이 바뀝니다. 기존 URL을 유지하려면 반드시 **배포 관리 → 수정 → 새 버전**으로 하세요.

### 반영이 안 될 때

브라우저 캐시 때문일 수 있습니다.

- `Ctrl + Shift + R` (강력 새로고침)
- 또는 시크릿 창에서 열기

**파일**: `index.html`


### 3-3. 문항 개수가 늘거나 줄었을 때

**두 파일을 모두 고쳐야 합니다.**

#### ① `Code.gs` — 읽어올 열 범위 수정

예를 들어 캠프 문항이 5개 → 6개로 늘었다면 (C~G에서 C~H로):

**위치**: `getCampData()` 함수 내부 (58번째 줄 근처)

```javascript
// 변경 전
scores: [row[2], row[3], row[4], row[5], row[6]]

// 변경 후 (row[7] 추가)
scores: [row[2], row[3], row[4], row[5], row[6], row[7]]
```

> **중요**: 컬럼 번호는 0부터 시작합니다. A=0, B=1, C=2, D=3, E=4, F=5, G=6, H=7, I=8, J=9, K=10, L=11, M=12, N=13, O=14, P=15

주관식 열 번호도 한 칸씩 밀리므로 함께 수정:

```javascript
comment1: String(row[8] || '').trim(),   // 기존 row[7] → row[8]
comment2: String(row[9] || '').trim(),   // 기존 row[8] → row[9]
```

#### ② `index.html` — 문항 목록에 추가

```javascript
const CAMP_ITEMS = [
  {label:'1. 참여한 프로그램 내용이 흥미로웠나요?', type:'prog'},
  ...
  {label:'6. 새로 추가된 문항', type:'prog'},   // ← 추가
];
```

> `Code.gs`의 `scores` 배열 개수와 `index.html`의 문항 목록 개수가 **반드시 일치**해야 합니다.

### 3-4. 새로운 설문(스프레드시트)을 추가하고 싶을 때

4단계로 진행합니다.

#### ① `Code.gs` 상단에 시트 ID 추가 (6~11번째 줄)

```javascript
const NEW_SS_ID = '여기에_스프레드시트_ID';
```

> 스프레드시트 ID는 URL에서 `/d/` 와 `/edit` 사이의 긴 문자열입니다.
> 예: `docs.google.com/spreadsheets/d/`**`1AbC2DeF3GhI`**`/edit`

#### ② `Code.gs`에 데이터 읽기 함수 추가

기존 `getCampData()`를 복사해서 이름과 열 번호만 바꾸면 됩니다.

```javascript
function getNewData() {
  const ss    = SpreadsheetApp.openById(NEW_SS_ID);
  const sheet = ss.getSheetByName('설문지 응답') || ss.getSheets()[0];
  const data  = sheet.getDataRange().getValues();
  const rows  = [];
  const yearSet = new Set();

  for (let i = 1; i < data.length; i++) {
    const row = data[i];
    if (!row[0]) continue;
    const d = parseTs(row[0]);
    if (!d) continue;
    yearSet.add(d.year);
    rows.push({
      year: d.year, month: d.month, day: d.day,
      newType: String(row[1] || '').trim(),
      scores: [row[2], row[3], row[4]].map(v => scoreToNum(String(v || '').trim())),
      comment1: String(row[5] || '').trim(),
    });
  }
  return { years: [...yearSet].sort(), rows };
}
```

#### ③ `index.html` — 탭 추가

**TABS 배열** (179번째 줄):

```javascript
{ id:11, label:'새 설문(종류A)', filter:'종류A' },
```

**탭 버튼 HTML** (155번째 줄 근처):

### 3-5. 응답자 분류를 바꾸고 싶을 때

설문 보기 항목이 바뀌면 분류 매핑을 수정해야 합니다.

#### 자유관람 응답자 분류

**파일**: `index.html`, **위치**: 240~253번째 줄

```javascript
const FREE_PART_ENTRIES = [
  ['학부모 등 보호자','학부모 등 보호자'],
  ['초등학생 학부모','학부모 등 보호자'],
  ...
];
const FREE_PART_CATS = ['초등학생','중학생','고등학생','교원','학부모 등 보호자','그외'];
```

- 앞의 값 = 시트에 실제로 들어오는 텍스트
- 뒤의 값 = 통계에 표시할 분류명

> ⚠️ **순서가 중요합니다.** `초등학생 학부모`가 `초등학생`보다 **위에** 있어야 합니다. 위에서부터 순서대로 검사하기 때문에, 짧은 키가 먼저 오면 잘못 매칭됩니다.

#### 학교·가족 프로그램 응답자 분류

**파일**: `index.html`, **위치**: 711번째 줄

```javascript
function mapProgRespondent(v) {
  const s = (v||'').trim();
  if (s.includes('학부모') || s.includes('보호자')) return '학부모 등 보호자';
  if (s.includes('학생')) return '학생';
  if (s.includes('교원') || s.includes('교사') || s.includes('교직원')) return '교원';
  if (s === '') return null;
  return '그외';
}
```

새로운 표현이 들어오면 여기에 조건을 추가하면 됩니다.

## 4. 문제 해결 (트러블슈팅)

### 증상: 코드가 텍스트로 그대로 보임

**원인**: `index.html` 파일이 없거나 이름이 잘못됨

**해결**:
1. Apps Script 왼쪽 파일 목록에 `index.html`이 있는지 확인
2. 없으면 **+ → HTML** 로 추가 (파일명은 `index`, `.html`은 자동)
3. 재배포

---

### 증상: 화면이 하얗게 비어 있음

**원인**: JavaScript 오류

**해결**:
1. `F12` 키를 눌러 개발자 도구 열기
2. **Console** 탭에서 **빨간색** 오류 메시지 확인
3. 오류 메시지에 나온 줄 번호 주변 코드 확인

---

### 증상: 숫자가 전부 0으로 나옴

**원인 1**: 컬럼 번호(인덱스)가 틀림

`Code.gs`에서 해당 설문 함수의 `scores` 배열 번호를 확인하세요. 스프레드시트 실제 열 위치와 맞아야 합니다.

**원인 2**: 만족도 표현을 인식 못 함

스프레드시트에서 실제 셀 값을 확인하고, `scoreToNum()`에 해당 표현이 있는지 확인하세요.

**확인 방법** — 브라우저 콘솔(F12)에서:

```javascript
google.script.run.withSuccessHandler(r => console.log(r.rows.slice(0,3))).getCampData()
```

결과에서 `scores` 배열이 `[null, null, ...]`이면 표현 인식 실패입니다.

---

### 증상: 특정 대상만 통계에 안 나옴

**원인**: 응답자 분류 매핑 누락

`index.html`의 `mapProgRespondent()` 또는 `FREE_PART_ENTRIES`에 해당 표현이 있는지 확인하세요.

**확인 방법** — 스프레드시트 빈 칸에:

```
=UNIQUE(C2:C)
```

실제로 어떤 값들이 들어오는지 확인한 후, 없는 값을 매핑에 추가합니다.

---

### 증상: 이미지가 안 보임

**확인 순서**:

1. `logo.html` 내용이 `data:image/png;base64,`로 시작하는지 확인
2. `data:image/png;base64,`가 **두 번** 반복되지 않았는지 확인
3. Apps Script에서 **실행 → getImages** 를 눌러 오류가 없는지 확인

---

### 증상: 새 데이터가 반영 안 됨

**해결**:
1. 웹앱 화면의 **↻ 새로고침** 버튼 클릭
2. 그래도 안 되면 `Ctrl + Shift + R`
3. 그래도 안 되면 재배포

---

### 증상: 권한 오류가 뜸

**해결**: Apps Script 편집기에서 아무 함수나 **실행** 버튼으로 한 번 돌려보세요. 권한 승인 팝업이 뜨면 승인하면 됩니다.

## 백업 권장 사항

코드를 수정하기 전에는 항상 백업을 남기세요.

**Apps Script 자체 버전 관리 사용법**:
1. **배포 → 배포 관리** 에서 이전 버전으로 되돌릴 수 있습니다.
2. 또는 수정 전 코드를 메모장에 복사해 두세요.

**파일로 백업하기**:
- Apps Script 편집기에서 코드 전체 선택(`Ctrl+A`) → 복사 → 텍스트 파일로 저장
